# 과천선 HUD 운전 시뮬레이터

철도전기기관사과 졸업작품 — **철도 운전 시뮬레이터 + 전면유리 HUD 운전 가이드** (JavaScript / three.js)

- 구간: 2종 전기차량 운전면허 **기능시험 구간 남태령 ↔ 산본** (과천선 ATC + 안산선 ATS), 상선·하선
- 차량: 10량 전동차, **투핸들** (동력 핸들 OFF~4단 / 제동 핸들 완해~7단~비상)
- 열차방호: ATC 차내신호(ADU: STOP·15·25·40·60·70·80) / ATS, 금정역 ATCCgS 절환
- 교직 절연구간(남태령~선바위): 회생제동 차단, 교직 절환 스위치(ADS), MCB, DC/AC 표시등
- 운전 가이드: 표준교재 「기능교재」 4장 **기본 운전 취급법**을 역간별로 넣고, 기관사가 벗어나면 **실시간 재계산 값**으로 지시

## 실행

설치할 것이 없습니다. `index.html` 을 크롬/엣지로 더블클릭하면 됩니다.
(three.js, 텍스처, 효과음, 폰트를 모두 폴더 안에 넣어 두어 인터넷 없이 동작합니다.)

## 조작

| 키 | 기능 |
|---|---|
| W / S · Q · A | 동력 핸들 올림/내림 · 4단 바로 투입 · OFF |
| ↓ / ↑ · 1~7 · 0 | 제동 핸들 체결/완해 · 해당 단 · 완해 (마우스 휠도 가능) |
| Space | 비상제동 |
| O | 출입문 열기/닫기 (정차 후, 정지 위치 ±5 m) |
| C | 교직 절환 스위치 (DC ↔ AC) |
| R | 회생제동 차단 스위치 |
| T | ATCCgS (ATC ↔ ATS, 정차 + 제동 4단 이상) |
| F | 지적 확인 환호 (HUD에 `☞ ○○` 가 뜨면) |
| H · B | 기적 · 발차 버저 |
| P | **자동운전** 켜기/끄기 (수동으로 핸들을 만지면 자동 해제) |
| G · U | 운전 가이드 표시 · HUD 전체 켜기/끄기 (HUD 유무 비교 시연용) |
| M · Esc | 소리 · 메뉴 |

발표 때 특정 지점부터 보여주려면 주소 뒤에 `?u=위치(m)&v=속도(km/h)` 를 붙입니다 (u = 출발역 방향 기준 거리).
예) 하선 `index.html?u=620&v=60` 절연구간 직전, `?u=1760&v=62` 선바위 진입, `?u=13900&v=45` 금정 진입(지상 구간)

## HUD 운전 가이드 — "어디서, 몇 단, 몇 km/h"

전면유리 가운데 지시 박스에 지금 해야 할 취급이 크게 뜹니다. 박스 태그 색으로 근거를 구분합니다.

| 태그 | 의미 | 예 |
|---|---|---|
| (태그 없음, 초록) | 교재 기본 운전 취급 그대로 | `동력 4단 — 약 70 km/h에서 동력 OFF` · `제동 2단 — 50 km/h에서 완해` · `초제동 2단 → 추가 4단` · `3단으로 계단 완해` · `1단으로 정차` |
| `보정` (주황) | 기관사가 기준을 벗어났거나, 선로 조건 때문에 기준값을 바꾼 지시. 이유를 함께 표시 | `동력 OFF — 기준 57 km/h 초과 +5` · `제동 4단 — 기준 65 km/h 초과(+7), 구간 끝까지 490 m → 4단 필요` · `추가 제동 5단 — 진입 속도 과다` · `동력 4단 → 55 km/h에서 OFF (타력 시 승강장 진입 18 km/h)` |
| `절연` (하늘) | 교직 절연구간 취급 순서 | `회생 차단 (R)` → `타행 — 동력 OFF` → `교류 전환 (C)` → `절연 구간 — 타행` → `역행 · 회생 복귀 (R)` |
| `정차` | 정차 후 | `정차 — 제동 4단 유지 · 정위치 +59 mm · 출입문 열기 (O)` |

그 밖의 HUD 표시:
- **다음 취급** 목록 (거리순): `☞ 과천 접근 280 m`, `65 km/h 되면 제동 2단 → 50 완해`, `과천 승강장 초입 · 초제동 2단 → 4단` …
- **지적 확인 환호** 프롬프트 `☞ 제한 75키로 [F]` (교재 2장 환호 용어)
- 속도, ADU 지시속도와 다음 코드·거리, 선로 제한속도 표지, 제동 개시까지 거리
- 정차 제동 중: **예상 정지 위치(±m)**, **권장 노치**, ±0.5 m 정위치 게이지
- 선로 위 AR: 제동 개시선 · 예상 정지선 · 정지위치 · ADU 코드 변경점 · 제한표지 · 절연구간
- 상태: ATC/ATS, ADS, 전차선 전원, MCB, 회생차단, 자동운전, 정시(기준 대비 지연)
- **정위치 표시**: 역 300 m 앞부터 정지위치까지 남은 거리(mm)와 미달/양호/초과 — 승강장 모니터와 같은 값

역마다 실제처럼 **승무원용 모니터**(CCTV 영상 + 승강장 안전문 정위치 표시 `미달 -1376 mm` / `양호 +059 mm` / `초과`)와
**진로 개통 표시기**(ATC 구간, 앞 폐색이 STOP이면 적색), ATS 구간에는 **출발·장내신호기**가 있습니다.

하단 계기판: TCMS(속도, 핸들, BC/MR 압력, 전차선, MCB·ADS, 공기압축기), **운전곡선**(상한·기준 운전선도·실주행·제동 개시점·예상 정지점, 교재 역간 설명), 투핸들 위치(가이드 권장 위치는 하늘색 테두리).

## 가이드 계산 원리 (발표용)

1. **운동 모델** (`js/physics.js`) — 가속도 = 견인력 − 제동력 − 주행저항 − 구배저항
   - 견인: 기동 3.0 km/h/s, 40 km/h 이상 정출력, 승차율에 따라 감소
   - 제동: 1단당 0.5 km/h/s (7단 3.5, 비상 4.5 km/h/s), 응하중이라 하중 무관
   - 공주시간 0.35 s + 제동력 상승 0.9 m/s³, 주행저항 a = 0.008 + 0.00008V + 0.0000025V²
2. **예측기** (`js/predictor.js`) — 현재 상태를 복사해 같은 모델로 0.1 s씩 앞당겨 적분
   - 예상 정지 위치, 목표(위치·속도)까지의 여유거리, 목표를 지키는 최소 노치, 타력/동력 후 도달 속도
3. **가이드** (`js/guide.js`, 초당 10회)
   - 교재 항목(역간별 동력 OFF 속도, 내림 기울기 제동 구간·속도, 재동력 구간, 정차 패턴)을 기준 지시로 사용
   - 전방 조건(ADU 코드 하강, 제한표지, 승강장 진입 60 km/h, 정지위치)을 예측기로 검사해서
     기준대로면 위반이 생길 때 / 기관사가 기준을 놓쳤을 때 **필요한 노치·완해 속도·OFF 속도를 다시 계산**
   - 정차: `초제동 2단(1.5 s) → 4단` 패턴으로 정지위치 4 m 앞에 서는 지점에서 제동 개시 →
     이후 "정지위치를 넘지 않는 가장 약한 노치"를 계속 계산하면 자연스럽게 4→3→2→1 **계단 완해**가 됨
4. **자동운전** (`js/sim.js` autoDrive) — 가이드 지시를 그대로 핸들(제동 1단씩 0.2 s, 동력 4단 즉시)·스위치·출입문·환호에 반영
5. **기준 운전선도** (`js/ref_data.js`) — 자동운전으로 전 구간을 달린 결과. 운전곡선의 점선과 정시 판정에 사용

검증 (`node tools/test_autopilot.js`):

```
[하선 (남태령 → 산본)] 완주 운행 28분 14초 · 속도초과 0회 · ATC 개입 0회 · 제동감도시험 done
  선바위 +141mm · 경마공원 +87mm · 대공원 +36mm · 과천 +101mm · 정부과천청사 +101mm · 인덕원 +127mm · 평촌 -111mm · 범계 +165mm · 금정 +74mm · 산본 +51mm
[상선 (산본 → 남태령)] 완주 운행 26분 15초 · 속도초과 0회 · ATC 개입 0회 · 제동감도시험 done
  금정 +68mm · 범계 +83mm · 평촌 +98mm · 인덕원 -162mm · 정부과천청사 +89mm · 과천 +166mm · 대공원 +136mm · 경마공원 +27mm · 선바위 +107mm · 남태령 +54mm
```
(선행열차 포함, 10개 역 모두 정위치 ±500 mm 이내)

## 노선 데이터 (`js/route.js`)

- 역간거리: 영업거리 (금정 0.0 / 범계 2.6 / 평촌 3.9 / 인덕원 5.5 / 정부과천청사 8.5 / 과천 9.5 / 대공원 10.5 / 경마공원 11.4 / 선바위 12.4 / 남태령 14.4 km, 금정~산본 2.3 km)
- 구배·경계표지·제한표지·취급 위치: 교재 서술(“2경계표지 지나 18‰ 내림” 등)을 바탕으로 배치한 **근사값**
- 과천정보타운역(신설)은 교재(2023) 시험 구간 기준이라 넣지 않았습니다.
- `RS.TEXTBOOK` 에 역간별 교재 항목이 그대로 들어 있습니다. 숫자를 고친 뒤 `node tools/build_ref.js` 로 기준 운전선도를 다시 만드세요.

## 에셋 (모두 무료·저작권 문제 없음)

자세한 출처는 `assets/LICENSES.md`.
- 텍스처·하늘: **Poly Haven (CC0)** — 터널 콘크리트, 콘크리트/자갈 도상, 승강장 타일, 역 벽 타일, 잔디, 하늘
- 효과음: **BigSoundBank (CC0)** — 지하철 차내 주행음, 터널음, 공기압축기, 출입문, 기적 등 (VVVF 인버터음은 합성)
- 폰트: **Noto Sans KR (OFL)**, 라이브러리: **three.js (MIT)**
- `assets/` 의 파일을 바꾼 뒤 `python3 tools/bundle_assets.py` 를 실행하면 `js/assets_bundle.js` 가 다시 만들어집니다
  (더블클릭 실행에서도 텍스처가 막히지 않도록 base64 로 묶은 파일).
