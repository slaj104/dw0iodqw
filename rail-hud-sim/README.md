# 과천선 HUD 운전 시뮬레이터

철도전기기관사과 졸업작품용 **철도 운전 시뮬레이터 + 전면유리 HUD** (JavaScript / three.js)

- 노선: 수도권 전철 4호선 **과천선 하행** (남태령 → 선바위 → … → 금정, 10개 역)
- 차량: 10량 전동차, 단일핸들 주간제어기 (P4 ~ N ~ B1~B7 ~ EB)
- 열차방호: **ATC 차상신호** (폐색구간별 속도코드, 과속 시 상용최대제동 자동체결)

## 실행 방법

설치할 것이 없습니다. `index.html` 을 크롬/엣지로 더블클릭해서 열면 됩니다.
(three.js 를 `vendor/` 폴더에 포함해 두어서 인터넷이 없어도 동작합니다.)

로컬 서버로 열고 싶으면:

```bash
cd rail-hud-sim
npx serve .        # 또는 python -m http.server
```

## 조작법

| 키 | 기능 |
|---|---|
| ↑ / W | 역행 쪽으로 한 단 (EB → B7 … B1 → N → P1 … P4) |
| ↓ / S | 제동 쪽으로 한 단 |
| 마우스 휠 | 주간제어기 이동 |
| N | 중립 |
| Space | 비상제동 (EB) |
| D | 출입문 열기/닫기 (정지위치 ±5 m 이내에서만) |
| H | HUD 켜기/끄기 (HUD 유무 비교 시연용) |
| M / Esc | 소리 / 메뉴 |

시연할 때 원하는 지점부터 바로 보여주려면 주소 뒤에 `?s=위치(m)&v=속도(km/h)` 를 붙입니다.
예) `index.html?s=950&v=55` (교직 절연구간 직전), `index.html?s=4600&v=50` (과천역 진입),
`index.html?s=12150&v=60` (지상 구간), `&leader=1` 을 붙이면 선행열차도 앞 역에 배치됩니다.

## HUD 표시 항목 (전면유리)

| 항목 | 내용 |
|---|---|
| 현재 속도 | 큰 숫자 + 0~100 km/h 속도 테이프 (ATC 허용속도 위치에 ▼ 표시) |
| ATC 허용속도 | 원형 표지에 현재 속도코드, 아래에 **다음 코드와 변경 지점까지 거리** |
| 제동 개시 지점 | "제동 개시까지 ○○ m" + 막대. 0 이 되면 `▼ 제동 개시` 점멸 |
| 예상 정지위치 | 제동 중일 때 "정지위치 대비 +3.2 m (과주 예상)" 같은 형태와 ±20 m 게이지 |
| 권장 노치 | 정위치 정차에 필요한 최소 제동노치 (예: 권장 B4) |
| AR 표시 | 선로 위에 **제동 개시선(하늘색)·예상 정지선(초록/주황)·정지위치(흰색)·ATC 코드 변경점(노랑)** 을 겹쳐 그림. 예상 정지 지점까지는 반투명 진로 표시 |
| 다음 정차역 | 역명, 거리, 출입문 방향(좌/우) |
| 전원 | DC 1500 V / 무전압(절연) / AC 25 kV, 현재 구배(‰) |
| 경고 | ATC 과속 자동제동, 허용속도 근접, 교직 절연구간 예고/통과 |

하단 계기판에는 TCMS 화면(속도·BC 압력·가속도·전차선 전압 등), 주간제어기 위치,
**운전곡선(거리-속도 그래프)** 이 표시됩니다. 운전곡선에는 ATC 허용속도(계단선),
B4 기준 제동곡선(점선), 실제 주행 궤적, 제동 개시 지점, 예상 정지점이 함께 그려집니다.

## 예측 알고리즘 (발표 자료용 요약)

1. **운동 모델** (`js/physics.js`)
   가속도 = 견인력 − 제동력 − 주행저항 − 구배저항
   - 견인: 기동가속도 3.0 km/h/s, 40 km/h 이상 정출력(가속도 ∝ 1/v), 승차율에 따라 감소
   - 제동: 노치당 0.5 km/h/s (B7 = 3.5 km/h/s, EB = 4.5 km/h/s), 응하중 제어로 하중 무관
   - 공주시간 0.35 s + 제동력 상승률 0.9 m/s³ (공기제동 응답지연)
   - 주행저항: a = 0.008 + 0.00008·V + 0.0000025·V² (m/s², V: km/h)
   - 구배저항: g × 구배(‰)/1000
2. **예상 정지위치** (`js/predictor.js` `predictStop`)
   현재 상태(위치·속도·현재 제동력·공주시간 잔여)를 복사해서, *지금 노치를 그대로 유지한다고 가정*하고
   같은 운동 모델로 0.1 s 단위 적분 → 속도 0 이 되는 위치. 앞쪽 구배 변화까지 반영됨.
3. **제동 개시 지점** (`brakeMargin`)
   목표(정지위치 또는 ATC 코드가 낮아지는 폐색 시점)마다 "지금 기준노치(B4)로 제동하면 필요한 거리"를
   위와 같은 방법으로 계산 → `여유거리 = 목표까지 거리 − 필요 제동거리`. 가장 작은 여유거리가 HUD에 표시됩니다.
4. **권장 노치** (`recommendNotch`)
   B1~B7 각각으로 예상 정지위치를 구해 정지위치를 넘지 않는 가장 약한 노치를 선택.
5. 계산은 초당 10회 수행.

노드에서 자동운전 검증 결과: 제동 개시 지점에서 B4 로 잡으면 정지위치 ±2 m 이내,
권장 노치를 따라가면 9개 역 모두 오차 약 0.3 m 로 정차했습니다.

## 과천선 특징 반영

- **교직 절연구간** (남태령~선바위): DC 1500 V(서울교통공사) ↔ AC 25 kV(코레일) 전환.
  절연구간 예고표·역행 OFF·역행 ON 표지, 전차선 색 구분, 판토그래프가 모두 통과할 때까지 역행 차단,
  HUD 에 잔여거리 표시. 절연구간 안에서 정차하면 경고.
- **좌·우측 통행 전환(꽈배기 구간)**: 남태령까지는 상행선이 왼쪽, 전환 구간(단선 터널) 이후에는 오른쪽.
  그래서 출입문 방향도 남태령은 우측, 선바위부터는 좌측입니다.
- **남태령~선바위 급구배** (-28‰): 타력운전 중에도 속도가 올라가서 ATC 과속에 걸리기 쉬움.
- **선행열차**: 과천역에서 2분간 정차하도록 설정되어 있어, 따라가면 25/45/0 코드 등 제한 코드를 받습니다.
  ATC 코드 = min(선로 제한속도, 선행열차와의 폐색 간격에 따른 코드).

## 노선 데이터 수정 (`js/route.js`)

역간거리, 곡선반경, 구배, 절연구간 위치, 폐색 분할 등은 **시연용 근사값**입니다.
선로일람표·종단면도 등 실제 자료를 구하면 `route.js` 의 숫자만 바꾸면 화면·물리·예측이 모두 따라 바뀝니다.
과천선 실제 신호방식/속도코드 체계도 조에서 한 번 확인해 보시고 `ATC_CODES`, `codeFromGap()` 을 맞추세요.

## 파일 구성

```
rail-hud-sim/
├─ index.html        시작 메뉴, 캔버스 배치
├─ css/style.css
├─ vendor/three.min.js
└─ js/
   ├─ route.js       노선 데이터 (역·곡선·구배·절연구간·ATC 폐색)
   ├─ physics.js     열차 운동 모델
   ├─ atc.js         ATC 차상장치 + 선행열차
   ├─ predictor.js   예상 정지위치 / 제동 개시 지점 / 권장 노치
   ├─ world.js       3D 터널·선로·역·전차선·표지 생성
   ├─ hud.js         운전실 프레임, 전면유리 HUD, 하단 계기판
   ├─ audio.js       효과음 합성
   └─ main.js        메인 루프, 입력, 정차 판정, 결과
```
