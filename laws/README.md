- 조문 수에는 `제N조의M` 가지 조문이 포함됩니다. 부칙은 제외했습니다.
- 별표는 `별표/` 폴더에 PDF 원본과 텍스트 변환본이 있습니다.
- `*.json`은 학습 프로그램(퀴즈·암기카드)용 조문 데이터입니다.
- 광역철도 운전취급 세칙은 law.go.kr에 없는 운영기관 세칙이라, 받은 PDF(`sources/`)를
  `scripts/parse_gwangyeok.py`로 변환했습니다. PDF 줄바꿈을 이어 붙이는 과정에서 띄어쓰기가
  드물게 어긋날 수 있습니다.
- 철도안전법 제5·11·41·45조의2·46·79·79조의2·80·81·82조는 law.go.kr 표시 그대로
  2026-12-17 시행 예정 개정 내용이 반영되어 있습니다(JSON의 `pending` 필드, md에 안내문).

개정되면 다시 받기: `python3 scripts/fetch_laws.py`
